❌ Vulnerable Implementation (vulnerable/api/login.php)
// ⚠️ INSECURE: Direct concatenation $u = $_POST['username']; $p = $_POST['password']; $sql = "SELECT * FROM users WHERE username = '$u' AND password_hash = '$p'"; $result = $conn->query($sql);

The single-quote terminates the string literal, and OR '1'='1' forces the condition to always evaluate to TRUE, while -- discards password verification.

✅ Fortified Implementation (api/login.php)
// 🛡️ SECURE: Prepared Statements with PDO $stmt = $pdo->prepare( "SELECT * FROM users WHERE username = :u" ); $stmt->execute([':u' => $username]); $user = $stmt->fetch(); if ($user && password_verify($pass, $user['password_hash'])) { ... }

SQL engine treats user input strictly as inert string data, rendering SQL syntax manipulation impossible.
