💉 SQL Injection (Auth Bypass)

Authentication form uses raw string concatenation in SQL queries without parameter binding, allowing attackers to login as administrator with simple boolean tautologies.

VULN-02 High (8.5)

🔓 Insecure Direct Object Reference (IDOR)

The dashboard blindly trusts the user_id URL parameter without verifying the authenticated session token, allowing customers to view balances and accounts of other users.

OWASP A01:2021 CWE-639 GET /api/get_accounts.php
🚀 Launch IDOR Lab
VULN-03 High (8.1)

🎭 Cross-Site Request Forgery (CSRF)

Money transfer API accepts state-changing POST requests without validating an anti-CSRF synchronizer token or checking the Origin header, enabling forced transactions.

OWASP A01:2021 CWE-352 POST /api/transfer.php
🚀 Launch CSRF Lab
VULN-04 High (7.5)

💾 Stored Cross-Site Scripting (XSS)

Transfer remarks accept raw script tags and store them in the database. When search queries or transaction histories are rendered, the malicious script executes automatically.

OWASP A03:2021 CWE-79 POST /api/transfer.php
🚀 Launch Stored XSS Lab
VULN-05 Medium (6.1)

🪞 Reflected Cross-Site Scripting (XSS)

The transaction search endpoint echoes back the user's search query directly into the HTML response without context-aware HTML entity encoding.

OWASP A03:2021 CWE-79 GET /api/search.php
🚀 Launch Reflected XSS Lab
VULN-06 Medium (6.1)

Client-side JavaScript reads unvalidated data from window.location.hash and directly writes it into the DOM using the dangerous sink element.innerHTML.

Statement download endpoint concatenates raw user input to a directory path without canonicalization or realpath() boundary verification, leaking server files like win.ini.

OWASP A01:2021 CWE-22 GET /api/download.php

Avatar upload endpoint fails to validate file extensions, MIME types, or magic bytes, and saves files in a public web directory under their original names, enabling Remote Code Execution.

OWASP A04:2021 CWE-434 POST /api/upload.php
🚀 Launch Upload Lab

Administrative functions can be directly invoked over HTTP without checking whether the authenticated session user possesses the required admin role permissions.

OWASP A01:2021 CWE-285 GET /frontend/admin.html
