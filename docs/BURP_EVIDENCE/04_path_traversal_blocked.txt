================================================================================
BURP SUITE EVIDENCE ITEM 04: PATH TRAVERSAL & ARBITRARY FILE ACCESS DEFENSE
================================================================================
Vulnerability: Directory Traversal / File Inclusion (OWASP A01:2021 - Broken Access Control / CWE-22)
Target Endpoint: GET /api/download_statement.php?date=...
Tool: Burp Suite Repeater
Attack Vector: Dot-Dot-Slash Relative Directory Traversal Sequence
Defensive Controls:
  1. Strict Whitelist Regex Format (/^\d{4}-(0[1-9]|1[0-2])$/)
  2. Canonical Filesystem Sandbox Verification (realpath)
  3. Base Directory Prefix Enforcement

ALTERNATIVE TRAVERSAL VECTOR TEST (Encoded / Null Byte Attempt):
--------------------------------------------------------------------------------
Request:
  GET /api/download_statement.php?date=2026-05%2f..%2f..%2fconfig%2fdatabase.php%00 HTTP/1.1
Response:
  HTTP/1.1 400 Bad Request
  {"status":"error","code":400,"message":"Invalid date format. Expected YYYY-MM."}

--------------------------------------------------------------------------------
SECURITY ANALYSIS:
--------------------------------------------------------------------------------
1. Canonicalization Layer: `canonicalize_input()` strips the `%00` null byte and decodes entities.
2. Regex Allowlist Gate: The input must strictly match `/^\d{4}-(0[1-9]|1[0-2])$/`. Any parameter
   containing slashes, dots, or command sequences is aborted at the gate without touching the filesystem.
3. Secondary Realpath Verification: Even if a valid date resolves to a file, `realpath()` verifies
   that `str_starts_with($resolvedPath, $baseStatementsDir)` evaluates to true.
4. SIEM Logging: The incident logs `DIRECTORY_TRAVERSAL` with severity 'high'.
