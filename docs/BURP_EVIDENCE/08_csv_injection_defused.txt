SECURITY MITIGATION ANALYSIS:
--------------------------------------------------------------------------------
1. Threat Vector: In vulnerable spreadsheet applications (Microsoft Excel, LibreOffice Calc),
   cells beginning with '=', '+', '-', or '@' are parsed as dynamic formulas or DDE execution
   commands, allowing attackers to execute arbitrary system binaries when victims open exported CSVs.
2. Sanitization Logic (`security/csv_safe.php` & `api/export_statement.php`):
     `if (preg_match('/^[=\+\-@\t\r]/', $value)) { return "'" . $value; }`
3. Neutralization Effect: Notice row 1 of the output:
     `"'=cmd|'/C calc'!A0"`
   The leading single quote forces the spreadsheet parser to treat the cell as raw string literals.
   No calculations, external network calls, or OS commands are executed.
