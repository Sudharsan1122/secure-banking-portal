--------------------------------------------------------------------------------
SECURITY ANALYSIS & FORENSIC LOGGING:
--------------------------------------------------------------------------------
1. Parameter Isolation: The PDO driver treats the entire payload string "admin' OR '1'='1' -- " 
   as the literal value of the :username placeholder. The single quotes and comment markers (--) 
   are treated as data characters, never altering the SQL parser's Abstract Syntax Tree (AST).
2. Error Masking: The application returns a generic 401 Unauthorized without leaking table 
   names, column definitions, or database driver versions.
3. SIEM Audit: Recorded in `security_logs` as event type LOGIN_FAILED with severity 'low'.
