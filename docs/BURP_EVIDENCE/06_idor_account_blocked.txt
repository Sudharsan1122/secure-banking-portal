================================================================================
BURP SUITE EVIDENCE ITEM 06: INSECURE DIRECT OBJECT REFERENCE (IDOR) DEFENSE
================================================================================
Vulnerability: Broken Object Level Authorization (OWASP A01:2021 - Broken Access Control / CWE-639)
Target Endpoint: POST /api/transfer.php
Tool: Burp Suite Repeater
Attack Vector: Horizontal IDOR - Attempting to Debit Another Customer's Account ID
Defensive Controls:
  1. Centralized Transfer Service (`security/transfer_service.php`)
  2. Multi-Account Tenant Ownership Verification (`WHERE id = :id AND user_id = :uid`)
  3. Pre-Lock Account Authorization Enforcement

Recipient: Account ID 3 (Alice Smith's Primary Savings)

SECURITY ANALYSIS:
--------------------------------------------------------------------------------
1. Tenant Isolation: In `security/transfer_service.php`:
     `$stmt = $pdo->prepare("SELECT id, user_id, balance FROM accounts WHERE id = :id");`
     `if ((int)$fromAccount['user_id'] !== $senderId) { return 403 Forbidden; }`
2. No Data Leakage: The response never discloses the victim's balance or account status.
3. SIEM Audit: `ACCESS_VIOLATION` is recorded with severity 'high', alerting the SOC team to
