Vulnerability: Cross-Site Request Forgery (OWASP A01:2021 - Broken Access Control / CWE-352)
Target Endpoint: POST /api/transfer.php
Tool: Burp Suite Repeater
Attack Vector: Forged Cross-Origin Transfer Submission Missing CSRF Token
Defensive Controls:

  2. Timing-Safe Token Verification (hash_equals)

--------------------------------------------------------------------------------
SECURITY ANALYSIS & FORENSIC LOGGING:
--------------------------------------------------------------------------------
1. Gate Verification: `require_csrf_token()` executes prior to parsing transfer parameters or
   initiating database transactions.
2. Missing Header Defense: Because the malicious origin could not read the victim's session
   token due to the browser's Same-Origin Policy (SOP), it could not provide the `X-CSRF-Token` header.
3. SIEM Audit: The failed attack triggers an immediate audit log entry:
   - Event: CSRF_FAILURE
   - Severity: high
   - User: Authenticated victim ID
   - IP: Attacker / Victim client IP
   - Timestamp: RFC3339 formatted record chained into the SHA-256 ledger.
