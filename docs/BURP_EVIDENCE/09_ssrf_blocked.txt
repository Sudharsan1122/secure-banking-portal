--------------------------------------------------------------------------------
SECURITY ANALYSIS:
--------------------------------------------------------------------------------
1. DNS Pinning & Inspection: `dns_get_record()` resolves the domain to an IP address before establishing
   any socket connection.
2. CIDR Range Matching: The resolved IP is compared against RFC 1918 and RFC 3927 subnets using bitwise
   masking. Loopback (`127.0.0.1`), IPv6 loopback (`::1`), link-local metadata (`169.254.169.254`), and
   private internal RFC 1918 addresses are dropped instantly.
3. SIEM Audit: Every SSRF probe logs an event of type `SSRF_BLOCKED` with severity `high`.
